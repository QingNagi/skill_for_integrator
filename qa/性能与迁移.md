# doc-integrator 性能与新环境验收

2026-11-27，比较上一版 `b354c7d` 与本轮优化。Windows 使用同一台 x64 机器、同一批虚构文件和独立应用缓存。首次安装测试保留正常的操作系统磁盘缓存。计时覆盖脚本实际运行时间，未计入模型思考时间。

## 耗时

| Windows 操作 | 旧版中位数 | 新版中位数 | 采样条件 |
|---|---:|---:|---|
| PowerShell 5.1 首次启动 | 6.413 秒 | 3.903 秒 | 最终启动器，固定同一载荷，3 次独立部署，包含真实中英文 OCR 验收 |
| PowerShell 7 首次启动 | 5.755 秒 | 3.541 秒 | 同上 |
| PowerShell 5.1 已安装后启动 | 0.490 秒 | 0.539 秒 | 9 次，含运行文件就绪检查 |
| PowerShell 7 已安装后启动 | 0.691 秒 | 0.659 秒 | 同上 |
| 模糊查找 4 个文件名 | 269 毫秒 | 138 毫秒 | 2,424 个文件名，7 次交替计时，候选列表与排序逐字一致 |
| 复杂规范建任务 | 0.381 秒 | 0.298 秒 | 5 组交替计时，直接调用业务 CLI |
| 复杂规范生成草稿 | 0.874 秒 | 0.753 秒 | 同上 |
| 已缓存的扫描页回读 | 0.832 秒 | 0.803 秒 | 同上，保留依赖与模型校验 |
| 小型电特性表生成草稿 | 0.393 秒 | 0.402 秒 | 同上 |

首次安装少启动两次 Python，保留载荷 SHA-256、CLI 导入和真实 PDF/OCR 自检。前一轮对照中，PowerShell 5.1 为 5.399→3.662 秒，PowerShell 7 为 5.220→3.494 秒，两轮合计观察到 32%–39% 的降幅。文件名查找在一次搜索内复用分词结果。Word 读取减少了重复遍历。小表草稿在这次采样中慢了 9 毫秒，Windows 热启动变化在 50 毫秒以内。

Linux 在原生 x86_64 和 ARM64 断网运行。每种架构用三个独立缓存测首次任务，再各测五次同版复用。Ubuntu 24.04（glibc 2.39）上，x86_64 首次及复用任务中位数为 2.805 秒和 0.289 秒，ARM64 为 2.797 秒和 0.345 秒。这两台运行器均无 LibreOffice，已验证请求转换时的错误提示。套装的兼容下限为 glibc 2.28，本轮原生计时的发行版为 Ubuntu 24.04。[两种 CPU 的原生验收](https://github.com/QingNagi/skill_for_integrator/actions/runs/46012899264)

## 换机器时会遇到什么

| 场景 | 复测结果 |
|---|---|
| 没装系统 Python 或 OCR | 从空应用缓存运行，使用套装自带的 Python、PDF 库和中英文模型。扫描案例正确回读第 1 页的温度、湿度及测点编号，并在缺少依据时等待用户确认。 |
| 用户已设置 `DI_OCR=off` 或 `DI_NO_VENDOR=1` | Windows 首次自检会验证随包组件；实际任务尊重原有设置。用户关闭 OCR 后，扫描件识别能力仍会受限。 |
| 启动时缺少业务 Python 模块 | 两种系统会检查打包时实际包含的模块。保留原始载荷时可恢复缺失文件，现有自定义规则和排版配置在恢复中保留。 |
| Windows 修复后提示临时文件被占用 | 用真实文件句柄模拟占用，0.8 秒的占用解除后可自动完成清理。5 秒的持续占用超过有限重试窗口时会报告拒绝访问；待占用解除后可重试。 |
| Windows 报 Word 无法创建工作文件 | 本机正式包在常规桌面用户权限下通过 Word 2010 的 DOCX→DOC→DOCX 往返。低完整性进程或不可写的 TEMP、Content.Word 缓存仍会触发该问题。技能会在启动 Word 前报告具体路径。 |
| 目录内有同名来件 | 精确查找列出每个路径。在本机 Claude Code 实测中，助手列出甲、乙两个来源并等待选择。自动命名的同名模板任务即使在同一秒创建也得到不同的任务目录。 |
| 来源目录含分号或模板名含方括号 | 对已存在的路径按字面值处理。批量清单可往返保存包含分号的来源。批量目标没有匹配项会返回错误，保留已有清单。 |
| 输入损坏后用原任务名重试 | 所有输入成功解析后才写入任务信息。修正损坏来件后可重试；已存在的同名显式任务仍受保护。 |
| 输入位于别处，工作区是新目录 | 草稿和审核报告在发起任务的工作目录下的 `整合输出/`。用 `--out` 可以指定其他可写目录。 |

精度核对覆盖了电特性表的 8 个实测单元格、章节正文与批注链接、OCR 页码和人工待答项。最终交付仍取决于实际提供的来源；缺少的章节或测量记录须由用户补充。旧格式转换和 PDF 导出依赖目标机已有的办公软件。发布评审状态见同目录的 [Tier 1 复核说明](README.md)。
